# Offline APK Extractor & Backup

אפליקציית Android מקומית בעברית לחילוץ APK וליצירת חבילת גיבוי שאפשר להעביר לכרטיס זיכרון או ב-Bluetooth.

## יכולות ראשוניות
- הצגת אפליקציות משתמש מותקנות וחיפוש.
- שמירת APK בחבילת גיבוי מקומית.
- ניסיון לכלול נתונים פרטיים באמצעות su כאשר Root זמין.
- פתיחת חבילת גיבוי וחילוץ APK להתקנה מחדש.
- שימוש מקומי ללא שרת.

## מגבלות
הקוד הנוכחי מנסה לכלול את תיקיית הנתונים הפרטיים בגיבוי באמצעות Root, אך שחזור הנתונים הפרטיים עדיין אינו ממומש. בשחזור הראשוני מותקן ה-APK בלבד. נדרשת עבודה נוספת כדי לשחזר נתונים בבטחה, לשמר UID והרשאות ולתמוך באפליקציות Split APK. אין להסתמך על הגיבוי היחיד לנתונים חשובים בלי לבדוק אותו.

## Build
GitHub Actions בונה APK debug באמצעות JDK 17.
